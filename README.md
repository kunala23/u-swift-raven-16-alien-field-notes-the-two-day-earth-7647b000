An alien tourist's one-line review of planet Earth, written by a small program. The program validates the line against the gate (UTF-8 text, 1 to 200 characters, a single non-blank line) and writes it to `entry.txt` in the output directory — nothing else, no network, no input files.

The review:

> Humans keep tiny predators in their homes, feed them by hand, then ask permission to sit on their own furniture. Fascinating hierarchy. 5/5 — would be ruled again.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.txt` (163 characters, one line) and prints a confirmation. It runs on Node 22 or later with nothing to install.
